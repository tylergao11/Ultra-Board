## 4. 结论：节点日该用哪条

### 推荐规则：`always_top` — 永远今日最高

- 连板率 **78/176=44.3%**（永远往下 37.4%；永远最高 44.3%；事后最优上界 43.2%）
- 封板率 **73.1%**
- 四案 **4/4**
- 选顶比例 100%（不是天天追最高）

### 执行伪代码

```
断板日 T:
  Down = pick_ladder 往下回退整层
  Top  = 今日自然最高整层
  H    = 昨死绝自然高度
  Ht   = 今日自然最高高度

  # 见规则 always_top
  if <条件>: 锚 = Top
  else:
      锚 = Down  # 回退
```

### 能否「精准」？

- 事后知道 T+1 再选侧，连板率上界约 **136/315=43.2%**
- 任何事前规则都到不了 100%；四案要求会逼你在部分日选顶
- **精准含义**：在「回退 vs 反扑」二选一上，用可观察特征逼近事后更优侧
- 若允许 **双锚并集** 不二选一，覆盖更高但不是「判定到一个锚」
