# 人工标签 v1（节点次日 · 纯往下锚层）

来源：用户对 6 个拿不准梯队的打法说明。

## 总原则（用户原话归纳）

1. **只打表现最好的那个**（层内不撒网）。
2. **发酵看主线/排名**，不能只信单票 theme 字面；存在 **题材错挂**（合富挂医药、实为海峡两岸/福建）。
3. **0 发酵 + 贴近板开 → 不打**（澄星）。
4. **有发酵 → 一字锚也可以**（孚日锂电 rank#1）。
5. **准备打某票但次日碰不到板 → 放弃**（安泰、道明）。
6. **无发酵小低开秒板** 可强过一字锚（安记 > 太阳）。
7. 一字：不排死一字；空间/表现最好者优先。

## 可结构化的规则标签（供训练）

| tag | 含义 |
|-----|------|
| `only_best` | 层内只做一个最好的 |
| `no_zero_ferment_near_limit` | 0发酵且近板开 → 不打 |
| `need_touch_board` | 计划标的碰不到板 → 放弃 |
| `theme_true_story` | 用真实炒作主线，不唯 theme 字段 |
| `ferment_ok_yizi` | 有发酵的一字可做（回封路径） |
| `weak_open_instant_board_beats_yizi` | 小低开秒板可优于一字锚 |
| `abandon_if_cannot_fill` | 打不到就放弃，不强追 |

---

## 训练注意

1. **theme 噪声大**：合富类必须允许「主线纠偏」或海峡两岸关联特征。
2. **结果标签 ≠ 意图标签**：安泰/道明「想打但没碰到」是 **过程标签**，不是 cont=0 就等于不该选。
3. **正样本**：合富、孚日、梦天、安记（用户认可路径）。
4. **负样本**：澄星（0发酵近板）。
5. **条件放弃**：安泰、道明（选了但 T+1 执行失败）。
