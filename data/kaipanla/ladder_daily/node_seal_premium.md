# 节点日定锚：次日封板率 + 封板后次日溢价

**口径（赚钱，不是最高板）**

- 节点日 T 定锚集合（等权看集合内每只，**不定票**）

- **① 次日封板率**：T+1 仍在涨停池且 `boards = T日boards+1`（连板晋级封死）

- 节点样本：需存在 T+1、T+2 交易日

## 读法（先定锚）

1. **① 封板率**高 = 锚层里次日更能连上，偏「能打板做接力」
2. **② 溢价**高 = 连上之后次日开盘更给分，偏「封板后收益空间」
3. 两套策略可能一个封板高、一个溢价高——对应不同赚钱段，不必合成一个命中率
4. 溢价缺失：T+2 未涨停时 zt_pool 无 open_pct，会低估「烂板/低开」样本；若要完整溢价需非涨停 OHLC（东财日线已有能力可补）
