## 口径建议
- **发酵强度 = rank_T（当日 theme 首板热度全市场第几）**，不看绝对家数
- rank=1 最热；无首板 theme → 最冷档
- **超预期/不及**：次日 rank 上升/下降（需 T+1 收盘才完整；盘中可看实时首板榜）
- 热门水下（R1-3+开盘<0）仍应是第一刀
- 冷门贴板（高 rank 数字 + 近板）对应澄星类弱结构
