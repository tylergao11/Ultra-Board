## 4. 给后续研究的含义

1. **同高/H-1** 占比高 → 「断了 H、下个四进五」是真实结构，对应**往上/反扑**
2. **更低(≤H-2)** 占比高 → 断后从底起来，对应**往下/高低切**
3. **∉顶∉往下** → 现锚规则漏斗有洞（节点日人还不在两套集合里）
4. 下一步可按节点打标签：`同高反扑` / `H-1` / `深切`，再叠炸板率做切/冲
