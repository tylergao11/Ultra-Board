# 定锚组合策略研究（正推 + 反推）

**阶段：只定锚（高度/候选层），不定票。层 hit = 后续自然高标落在锚集合内。**

节点 **91**；评估窗 T+1~10。

## 一、反推：事后主高标在节点日站在哪

有后续自然高标的节点：91

| 位置 | 次数 | 占比 | 含义 |
|------|------|------|------|
| 节点日已在**今日自然最高层** | 14 | 15% | 顶锚该吃 |
| 在池但**低于**今日最高 | 24 | 26% | 底/中位，回退该吃 |
| 节点日**还不在涨停池** | 53 | 58% | 更后启动，任何当日锚都难 |

| 与两套候选关系 | 次数 |
|---------------|------|
| 只在顶层 | 3 |
| 只在往下锚层 | 5 |
| 两层都有 | 11 |
| 两层都没有 | 72 |

落入顶集合：14/91=15%；落入往下集合：16/91=18%

**反推结论（硬的）：**

- 约 **15%** 的主高标在断板日已经站在「今日自然最高」→ **回退若跨过最高层会系统性漏这一大块**。
- 约 **5%** 只在往下锚里 → **纯顶会漏从底起来的**。
- 约 **79%** 两边都没有 → 当日锚有理论上限，不能 100%。
- 合理形态不是二选一，是 **条件顶 + 底保留（dual 或 top_else_down）**。

## 三、研究结论：推荐组合（直接可用）

### 推荐：`dual|top_near_thin`

**顶条件满足则顶∪底否则底 + 近死绝且n≤2**

- 层 hit：**72/91 = 79%**（纯往下 68%；纯最高 62%）
- 四案：**4/4**（纯往下 0/4）
- 顶锚触发率：55% 的节点会动用顶
- 救回「仅顶」路径：10；保住「仅底」：19

### 规则正文（定锚）

```
断板日 T（自然高标死绝，同高公告不续命）：
1) 底锚 = 现行往下 pick_ladder（一字→重组→二板），得到高度 Hd 与层 Down
2) 顶层 = 今日自然最高高度 Ht 与自然层 Top
3) 顶锚是否激活（推荐门控 = 近死绝且薄层）：
     Ht >= dead_h - 1  且  |Top| <= 2
4) 组合（推荐 dual）：
     若顶激活：锚集合 = Top ∪ Down   // 顶底并行，不定票
     否则：锚集合 = Down
5) 定票阶段另做；本阶段只输出锚集合/双高度
```

### 为何是这个而不是别的

1. **反推**：主高标约四成已在顶层、仅底也有一块 → 必须能吃顶且不能废底。
2. **纯往下**：四案 0/4，回退跨过活着的最高板。
3. **纯最高**：仅底路径整段丢。
4. **top_else_down（有顶就丢掉底）**：顶触发日若真主升其实在底，会误伤；dual 用并集避免误伤（定锚阶段允许集合偏大）。
5. **门控不用 always**：always 顶触发率 100%，很多弱最高也并进集合；近死绝+薄层对准反扑带（同高/差一板独苗或双雄），减少无意义并集。

## 四、可执行优先级

1. **落地默认**：`dual + 近死绝且 n≤2`（上文推荐）
2. **若更怕漏反扑、不怕集合大**：`dual + top_always`
3. **若只要一个高度叙事、不要并集**：`top_else_down + 近死绝且 n≤2`
4. **定票**：在锚集合内再做额/竞价/晋级，不在本阶段做
