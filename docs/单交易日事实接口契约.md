# 单交易日事实接口契约 v1

## 1. 目标

接口面向其他 Agent。每次请求只返回一个交易日，避免把多日事实、路径和迁移视图
重复放入同一上下文。默认日响应只提供快速观察需要的最小事实；重型同花顺字段与
个股故事通过批量详情接口按需取得。

题材故事随日概览默认返回，但会剥离其中的个股详情。数据层只组织来源事实，不输出核心、强弱、爆发、打断、对手、皇位继承、高低切、
接力、反攻、评分、买点或最优解。

## 2. 唯一正式入口

### 2.1 查询可用日期

```http
GET /api/v1/calendar
```

调用方只能从 `available_dates` 选择日期。不得把自然日自行当作交易日。

### 2.2 查询一个交易日

```http
GET /api/v1/day?date=2026-07-24
```

`date` 必填且只能出现一次。响应中的 `information_cutoff` 与 `trade_date` 都等于
该日期。响应只包含这一天，不隐式携带前四日或下一日数据。

### 2.3 批量查询个股详情

```http
GET /api/v1/stocks?date=2026-07-24&code=600123&code=000001
```

也可以使用精确股票名称，并允许代码与名称混用：

```http
GET /api/v1/stocks?date=2026-07-24&code=600123&name=某某股份
```

`code` 和 `name` 都可重复传入。接口先在指定日期的来源股票集合中精确定位，随后
按股票代码去重。单次最多 32 个唯一选择器。

批量详情是原子响应：任一选择器不存在、名称不能唯一定位、个股故事缺失或故事正文
为空，整次请求失败，不返回残缺列表。

## 3. `/day` 参数合同

| 参数 | 必填 | 可重复 | 语义 |
| --- | --- | --- | --- |
| `date` | 是 | 否 | 唯一交易日，格式 `YYYY-MM-DD` |
| `theme` | 否 | 是 | 精确匹配开盘啦主属性或候选属性，最多 8 个 |
| `theme_match` | 否 | 否 | `any`（默认）或 `all`；未传 `theme` 时禁止使用 |
| `board` | 否 | 是 | 精确同花顺板数，多值取并集，最多 16 个 |
| `min_board` | 否 | 否 | 最低板数，含边界 |
| `max_board` | 否 | 否 | 最高板数，含边界 |

组合规则：

- 多个 `theme` 在 `theme_match=any` 时任一命中，在 `all` 时必须全部命中；
- 多个 `board` 取并集；
- 题材维度与梯队维度取交集；
- `board` 不得与 `min_board` 或 `max_board` 同时使用；
- `min_board` 不得大于 `max_board`；
- 未传任何范围参数时，返回当日全部来源股票，包括全部首板与更高板。

示例：

```http
# 智能电网首板
GET /api/v1/day?date=2026-07-24&theme=智能电网&board=1

# 智能电网或机器人，二板及以上
GET /api/v1/day?date=2026-07-24&theme=智能电网&theme=机器人&theme_match=any&min_board=2

# 同时具有 AI应用和机器人两个属性，二板到四板
GET /api/v1/day?date=2026-07-24&theme=AI应用&theme=机器人&theme_match=all&min_board=2&max_board=4

# 精确获取一板、二板和五板三个梯队
GET /api/v1/day?date=2026-07-24&board=1&board=2&board=5
```

## 4. 日概览响应

顶层结构：

```json
{
  "schema_version": 1,
  "api_version": "v1",
  "view": "single_day_facts",
  "data_revision": "sha256:...",
  "information_cutoff": "2026-07-24",
  "trade_date": "2026-07-24",
  "scope": {},
  "source_contract": {},
  "coverage": {},
  "day": {},
  "navigation": {
    "previous_available_date": "2026-07-23",
    "next_available_date": "2026-07-27"
  }
}
```

`navigation` 只提供日期指针，不复制其他日期的数据。调用方要看其他日期时，再次调用
`/day` 并替换 `date`。

`day.stocks[]` 每只股票只包含：

```json
{
  "code": "600123",
  "name": "某某股份",
  "boards": 2,
  "board_type": "换手板",
  "main_theme": "智能电网",
  "themes": ["智能电网", "机器人"],
  "first_limit_time": "09:31:08"
}
```

`day.theme_stories` 默认返回当日同花顺题材故事：

```json
{
  "source": "tonghuashun_strong_wind_headlines",
  "source_image": "...",
  "records": [
    {
      "source_position": 1,
      "context": "智能电网",
      "story": "当日来源故事原文",
      "headline": "智能电网：当日来源故事原文"
    }
  ]
}
```

`theme_stories.records[]` 不携带 `stocks`。`context` 是同花顺题材故事的来源标签，
不能用来覆盖开盘啦个股 `theme/themes`。

以下字段不进入默认日概览：价格、涨幅、流通市值、总市值、换手率、封单金额、
封单数量、封单占比、终封时间、开板次数、真一字、连板日期证据、个股故事。
它们全部由 `/stocks` 按需返回。

## 5. 批量详情响应

```json
{
  "view": "stock_details",
  "information_cutoff": "2026-07-24",
  "trade_date": "2026-07-24",
  "count": 2,
  "stocks": [
    {
      "matched_selectors": [{"by": "code", "value": "600123"}],
      "stock": {
        "date": "2026-07-24",
        "code": "600123",
        "name": "某某股份",
        "attributes": {},
        "limit_facts": {}
      },
      "stories": [
        {
          "source_position": 1,
          "headline": "...",
          "context": "...",
          "sector_story": "...",
          "stock_story": {"name": "某某股份", "story": "..."}
        }
      ]
    }
  ]
}
```

同一股票可命中多个同花顺故事，`stories` 因此是非空数组，不是单值。`context` 只保留
来源上下文，不能作为个股题材；`stock_story` 不能覆盖开盘啦 `theme/themes`。

## 6. 故事完整性硬门槛

- 正式导出不提供 partial stories 模式；
- `--ready-only` 只允许整体跳过不完整日期，不允许裁剪单日股票或故事；
- 正式导出先在同级临时目录完成全部日期校验，再原子替换公开目录；失败时旧修订保持不变；
- 故事来源缺失的日期不得进入 `available_dates`；
- 个股详情故事缺失或正文为空时返回 `503 STOCK_STORY_INCOMPLETE`；
- 不允许返回 `story: null`，也不允许使用默认文案、新闻、题材或人工关键词补造；
- 批量请求中任何一只股票不完整，整批失败；
- 日概览不展示个股故事只是响应分层，不代表故事可以缺失。

## 7. 精确定位与错误

| 状态 | 错误码 | 含义 |
| --- | --- | --- |
| 400 | `UNKNOWN_QUERY_PARAMETER` | 出现合同外参数 |
| 400 | `DUPLICATE_QUERY_PARAMETER` | 只能出现一次的参数被重复传入 |
| 400 | `INVALID_DATE` | 日期格式错误 |
| 400 | `INVALID_THEME_MATCH` | 题材组合模式非法 |
| 400 | `BOARD_FILTER_CONFLICT` | 精确板数与板数范围同时出现 |
| 400 | `INVALID_BOARD_RANGE` | 板数范围反向 |
| 400 | `STOCK_SELECTOR_REQUIRED` | `/stocks` 未传 code/name |
| 404 | `DATE_NOT_FOUND` | 日期未正式发布 |
| 404 | `STOCK_NOT_FOUND` | 至少一个股票选择器未命中 |
| 409 | `AMBIGUOUS_STOCK_NAME` | 名称无法唯一定位，必须改用代码 |
| 503 | `STOCK_STORY_INCOMPLETE` | 个股故事缺失或正文为空 |
| 503 | `DATA_CONTRACT_ERROR` | 已导出组件不符合 Schema |

接口不做股票名称模糊搜索，不静默忽略错误选择器，不返回部分成功结果。

## 8. 来源所有权

- 个股题材：仅开盘啦 `theme` 与 `themes`；
- 板数、价格、市值、换手、封单、封板时间、板型与真一字：仅同花顺
  `data/ths/limit_pool/`；
- 板块与个股故事：仅同花顺 `data/ths/stories/`；
- 同花顺 `reason_type`、故事标题 `context` 和新闻都不能覆盖开盘啦个股题材；
- 任意查询结果都必须携带 `information_cutoff`，不得使用 T+1 结果倒灌。

## 9. 机器发现

- `GET /api/v1`：公网机器入口，返回可直接继续访问的绝对端点地址与调用顺序；
- `GET /api/v1/meta`：查询边界、参数上限和禁止分析字段；
- `GET /api/v1/guide`：Agent 调用顺序与维护经验；
- `GET /api/v1/openapi`：OpenAPI 3.1 合同；
- `GET /api/v1/themes?date=T`：单日题材索引；
- `GET /api/v1/stories?date=T`：不含个股详情的单日板块故事；
- `GET /api/v1/news/sources`：外部新闻与公告地址白名单。
