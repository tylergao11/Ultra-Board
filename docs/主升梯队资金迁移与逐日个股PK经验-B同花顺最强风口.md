# B 口径：同花顺“最强风口”节点与梯队模型

本文是独立于开盘啦 A 口径的并行研究文档。A 口径继续保持不变；B 口径只使用同花顺“涨停聚焦 → 最强风口”直接展示的大类分组，不把同花顺个股详情里的多条副标签重新组合成我们自己的题材分类。

当前先锁定节点与模型合同，再用既有人工确认样本做 A/B 对照。B 口径没有完成历史重跑前，不继承 A 口径的模型样本数、出现率或成功率。

## 一、唯一分类源

1. 个股当天的大类，默认只认同花顺“最强风口”页面把它放入的主分组，例如“并购重组”“金融科技”“电子化学品／电子特气”“煤炭”。
2. 正常明确大类不读取或拆分个股事件介绍的其余副标签，不因副标签中出现“预增、国资、重组、控制权变更”等词再次改类。
3. 唯一例外是同花顺把股票放入“其他”“其他概念”或同义未分类兜底项：此时逐股人工读取该股票行的事件介绍。由公司公告直接驱动的股票统一改归“公告题材”，非公告驱动的股票改归真实自然题材，不继续保留“其他”。比如 2025-11-27 金富科技因“拟收购”改归“公告题材”。原始页面证据由当天图片保留。
4. 不建立覆盖正常大类的本地题材同义词表，不把若干细概念人工合并成一个大类；“其他”派生题材只做逐股人工判断，禁止正则、关键词或规则表自动归类。
5. 同花顺大类的页面顺序直接作为当日风口顺序；进攻模型仍只看前二大类。
6. 如果同一股票在页面存在多个展示位置，以同花顺明确展示的主归属为准，不由算法自行挑选更有利的类别。

## 二、B 口径的公告题材

B 口径不维护开盘啦式公告分类表，只做一个直接判断：

- 同花顺主分组明确写为 **“公告”** 时，直接按公告题材处理，不得当作自然题材；
- 页面已有明确大类时完全按该大类，不读取行内事件介绍另行改类；
- 只对原分组为“其他/其他概念/未分类”的股票逐条人工读取事件介绍；
- 其中由并购重组、拟收购、控制权变更、股权转让、业绩公告、摘帽等公司公告驱动的股票，最终统一改归 **“公告题材”**，不再细分公告子类；
- 不属于公告驱动的“其他概念”股票，由人工改归真实自然题材；
- 脚本不得用正则、关键词或规则表提出或写入题材建议，未完成人工审核时必须保留待审 issue。

公告题材排除同时作用于两个位置：

1. 前一交易日最高有效梯队与节点触发；
2. 节点日选层、进攻模型最高自然层和防守模型自然候选资格。

公告票不能成为自然候选；若它是真一字，只能在防守结构中作为量能锚。

例如 2026-08-06 的同花顺页面把爱丽家居放在“并购重组”大类，且它是十板高度，因此爱丽家居当天属于公告高度。以后爱丽家居断板，不能仅因它断板生成节点。

### “其他概念”逐股人工审核协议

任何 Agent 审核历史数据时都必须执行以下流程，脚本不得代替人工判断。

1. **限定审核范围**：只审核原图中位于“其他”“其他概念”“未分类”的股票。原图已有明确大类的股票保持页面分类，不在这一步重做。
2. **先看当天环境**：先阅读当天“最强风口”的全部明确大类、涨停聚集方向与事件背景，再判断“其他概念”股票。禁止脱离当天热点，只凭一个词决定题材。
3. **完整阅读事件**：逐股阅读图片里的完整事件介绍，不能只截取第一个或最后一个标签，也不能按标签出现顺序机械决定主因。
4. **先找真实驱动**：事件介绍中的标签只是候选证据，最终要回答“当天资金为什么把它封到涨停”。优先检查事件发生时间、当天市场主线、同方向涨停聚集、该股封板时点与板块启动／扩散顺序，并做反事实判断：如果拿掉这条事件，该股当天是否仍大概率涨停。
5. **判断驱动性质**：找到真实主驱后再分两类：
   - 能在市场中复制、形成一批股票共同炒作的行业、产业或概念逻辑，归入对应的自然题材；
   - 只属于该股票自身的独立事件，统一归入“公告题材”。这里的“公告题材”是模型用的独立事件总称，不要求事件已经正式确认。
6. **独立事件边界**：拟收购、并购重组、资产注入、资产出售、股权转让、控制权变更、国资入主、重组或控制权变更的传闻／预期、业绩预增、重大合同或订单、中标、战略协议、定增、增资、H 股递表、复牌、退市等，只有在人工确认其为当天真实封板主驱时，才统一写为“公告题材”；不得看到这些词就无脑判公告。
7. **自然题材边界**：机器人、AI应用、算力、芯片、光伏、黄金、农业、化工等只有在人工确认其为当天真实封板主驱时，才写入对应自然题材；不得看到概念词就无脑判题材。公司历史业务、静态合作关系或顺带概念不能自动认定为主因。
8. **封板时序核对**：主驱拿不准时，必须对照该股首次封板时间与候选板块当日核心股、首板群的封板先后。与板块同一波启动、跟随板块扩散的，支持自然题材；脱离板块独立封板、由个股消息直接触发的，支持公告题材。封板时序是判断证据，不是单独的机械规则。
9. **混合事件处理**：事件介绍同时含自然概念和独立事件时，综合当天热点强度、同方向涨停聚集、事件的新旧、封板时序和传播关系确定唯一主驱。传闻或预期虽未确认，若实际驱动该股独立封板，仍归“公告题材”；若只是顺带标签、真实封板随板块联动，则归自然题材。
10. **业绩行情处理**：不能因为“年报预增”排在事件介绍后面就忽略，也不能看到预增就自动判公告。应结合当天是否存在业绩预增集中炒作及该股封板时序确认主驱；例如 2026-01-28 农发种业、2026-01-29 锐明技术需要结合当日年报／业绩预增板块联动审核。
11. **不确定就挂起**：人工仍无法确认主驱时，保留待审 `issue` 并交由用户确认，禁止猜测，也禁止为了清零 issues 强行归类。
12. **结构化落地**：人工结论写入 `data/ths/strong_wind_manual_reviews.json`，每条必须保存 `date + code + name + event + theme`。最终 `theme` 只能是“公告题材”或人工确认的自然题材，最终逐日 JSON 不得残留“其他概念”。

标准执行顺序：

1. 串行 OCR 原图，列出全部“其他概念”股票及事件原文；
2. 人工逐图、逐股审核并填写审核文件；
3. 用审核文件回刷逐日 JSON；
4. 检查待审覆盖率、`issues=0`、无“其他/未分类”残留、无重复股票；
5. 抽查公告题材和自然题材样本，确认与原图事件及当天热点一致。

严禁创建或恢复题材正则表、关键词映射表、自动建议器；程序只能提取原文、读取人工结论和校验完整性。

## 三、B 口径节点日

节点仍是最高有效梯队的集合事件，不是任意一只高位股断板：

1. 在交易日 `T-1` 收盘，先找全市场二板及以上股票。
2. 对每只股票读取 `T-1` 当天最终有效分组；明确公告大类与由“其他概念”人工改归的“公告题材”都不进入有效最高梯队。
3. 在剩余股票中确定最高有效板 `H` 及该层全部成员。
4. 到交易日 `T`，只要 `H` 层仍有一只晋级 `H+1`，`T` 就不是节点日。
5. `H` 层全部断板时，`T` 才是 B 口径节点日。
6. 身份不追溯、不继承：只看股票在最高板当日被同花顺放入的主分组。

这条规则的口语版是：**前一日最高板没有被同花顺主分组直接归为公告高度，它断板的交易日就是节点日；同层有多只时必须全部断板。**

## 四、B 口径进攻模型

B 口径进攻模型保留“最高有效自然梯队进攻”的结构，只替换题材真相源：

1. 只在 B 节点日判断，并冻结在节点日收盘。
2. 剔除同花顺主分组直接认定的公告高度后，只在最高有效自然板判断进攻模型；一字或换手不是进攻模型的成立门槛。
3. **只看节点日当天**：该股票节点日的同花顺主分组必须位于当天“最强风口”前二大类。
4. 节点日该大类必须有低位涨停支持；不能只有一只孤立高标。
5. 低层同时出现防守结构时，仍以最高有效自然梯队的进攻模型为主模型，防守模型只记次级重叠。

沿途历史大类不进入 B 口径进攻模型判定：即使股票二板、三板时曾属于当天前二风口，只要节点日当前大类不在前二，就不触发进攻模型；反过来也不需要证明沿途题材连续。

因此，**进攻模型的结构保留，但 A 口径进攻模型不能直接当作 B 口径进攻模型样本**。同花顺节点日大类的成员与顺序可能和开盘啦不同，必须重新跑样本；原有进攻模型样本数和概率不继承。

## 五、B 口径防守模型

B 口径防守模型保留真一字防守结构：

1. 真一字仍是硬门槛；必须是开盘价、最高价、最低价一致的一字涨停。T 字、开板回封、高开快速封板都不是防守模型的一字锚。
2. 从最高有效自然层向下检查，首个同时具有真一字锚和自然候选的梯队形成 B 口径防守模型。
3. 节点日选层同样执行五类公告大类排除。公告一字可以作量能锚，但不能单独提供自然候选资格。
4. 同层换手票是确认和执行支持，不是防守模型硬门槛。
5. 若最高有效自然层同时命中 B 口径进攻模型与防守模型，主模型仍记进攻模型，防守模型记次级重叠。

因此，**防守模型的真一字核心比进攻模型的题材触发更少受分类换源影响**：真一字、梯队高度和同层结构都是价格与板型事实，不依赖题材源；但公告题材排除和节点日期可能改变，所以 A 口径防守模型的历史统计仍不能直接继承给 B 口径防守模型。

## 六、A／B 结论

| 项目 | A：开盘啦市场动向 | B：同花顺最强风口 | 是否可直接继承 |
|---|---|---|---|
| 涨停、连板、断板、一字／T字 | 开盘啦及日 K | 同花顺及日 K | 可以对账，结构不变 |
| 个股当天题材 | 开盘啦梯队 theme | 同花顺最强风口主分组 | 不可直接继承 |
| 公告题材 | 本地公告分类表匹配开盘啦 theme | 同花顺明确公告大类，或“其他”人工改归公告题材 | 不可直接继承 |
| 节点日 | 最高自然梯队全部断板 | 最高 B 有效梯队全部断板 | 必须重跑 |
| 进攻模型触发 | 开盘啦市场动向前二 | 同花顺最强风口前二 | 模型结构保留，样本重跑 |
| 防守模型触发 | 真一字锚＋自然候选 | 真一字锚＋B 自然候选 | 核心结构保留，样本重跑 |
| 历史概率 | A 样本账本 | B 独立样本账本 | 禁止混算 |

当前判断：

- **防守模型结构保留**，但应建立 B 口径独立统计；预计比进攻模型更少受分类换源影响。
- **进攻模型结构也保留**，但它对大类归属和前二顺序高度敏感；必须用同花顺历史“最强风口”逐日重跑后，才能知道原有进攻模型样本保留多少。
- 换源最可能改变的是节点日期和进攻模型触发，不是模型的价格结构本身。

## 七、首批 A／B 对照样本

首批只重跑已经人工确认的 11 个主模型样本，不读取盲测隔离区，也不使用节点日后的结果反改选层：

- A 口径防守模型：2025-10-30（3板）、2025-11-27（4板）、2025-12-04（3板）、2025-12-10（4板）、2025-12-16（4板）、2025-12-22（4板）、2025-12-30（5板）、2026-01-08（4板）。
- A 口径进攻模型：2025-12-19（4板）、2025-12-24（5板）、2026-01-05（4板）。
- 2025-12-19 的三板防守结构仍作为次级重叠单列，不重复计入主模型份额。

每个样本固定比较五项：

1. A 节点日在 B 口径下是否仍是节点日；
2. 最高板前一日的同花顺主分组及是否属于公告题材；
3. B 节点日最强风口前二；
4. 最高有效自然票节点日当前大类是否命中前二，以及 B 冻结梯队与主／次模型；
5. 与 A 相比是“完全一致、只换分类、换模型、换梯队、节点消失”中的哪一种。

在这 11 个样本全部完成前，只报告逐日差异和样本数，不报 B 模型概率。
