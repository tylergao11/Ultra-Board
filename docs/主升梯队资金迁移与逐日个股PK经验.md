# 第一阶段统一梯队算法

当前只解决节点日收盘后的**梯队选择与模型定位**。个股买谁、是否买得到、次日竞价和成功率属于第二阶段，不得倒灌第一阶段。

## 一、信息边界

- 输入日期为节点日 `T`。
- 只读取 `T` 及以前的原始涨停池和 `information_cutoff=T` 的派生快照。
- 禁止读取 `T+1` 竞价、盘中结果、后续高度、收益和人工答案。
- 人工标签只允许由显式回测命令读取，普通选层入口永不访问隔离区。
- `theme` 只取开盘啦梯队列表字段；不读取个股详情页属性。自然票保留当前连续连板路径从二板起逐日真实出现的全部 `theme`。
- 禁止从 `concepts`、主营、静态概念堆、后来新闻或地域关系补题材；地域暂不参与。

安全入口：

```bash
python -m ultraboard.kaipanla.ladder_evidence node 2026-06-01
python -m ultraboard.review.ladder_selector select 2026-06-01
```

## 二、公告身份

公告型 theme 的唯一分类表是 `data/kaipanla/announcement_taxonomy.json`，统一涵盖：

- ST摘帽、举牌；
- 一季报、半年报／中报、三季报、年报；
- 订单、中标、重大合同、业绩预增等公司公告；
- 并购重组、实控人变更、股权转让、再融资等资本事项。

公告身份不看整段路径，只看股票最高板当天的梯队 theme；判断断板票时即看断板前一交易日 theme。更早的公告或自然身份均不继承。最高板 theme 属于公告分类表时，该票为公告票；否则为自然票。ST 在这里仅指 ST摘帽，不包含仍戴帽的 ST／*ST 股票。公告票不从市场结构中删除，但不能作为自然候选，也不计入自然题材发酵：

- 公告真一字：角色为“量能”，可帮助同层形成防守模型。
- 公告换手板：只保留为梯队结构，不进入第二阶段候选池。
- 分类只读最高板日梯队 theme；禁止在算法中按股票名、节点日期或静态概念写特判。

## 三、涨停原因发酵榜

进攻模型严格复刻节点日开盘啦“市场动向”榜：家数使用开盘啦板块报告值，同家数按开盘啦涨停池中同 theme 股票的成交额合计降序，完全相同时再按接口源位置稳定排序；最高连板不参与该榜排序。排序后严格取红色第一名和橙色第二名。2026-03-31 与 2025-11-10 的同期客户端画面已核对；2025-11-10 的芯片与化工同为 6 家，芯片 86 亿排在化工 55 亿之前，尽管化工最高 3 板而芯片最高仅 1 板。

首板数量仅作解释材料，不参与排名。

## 四、统一决策

### 1. 最高自然梯队

先保留全部二板及以上股票，再按各票最高板当天 theme 剔除公告票，得到最高自然板 `H`。进攻模型只能在 `H` 判断，禁止因为中位梯队题材更强而向下搜索进攻模型。

### 2. 进攻模型

若 `H` 层至少一只自然票的沿途 theme 满足以下条件，则 `H` 命中进攻模型：

- 该题材位于节点日开盘啦市场动向榜前二；
- 命中关系来自该股票当前连续连板路径从二板起真实出现过的任一 `theme`。

等价判定：`H 层自然票二板起沿途 theme 集合 ∩ 节点日市场动向榜前二 ≠ ∅`。早期 theme 即使属于公告分类，也只作为沿途题材证据，不改变最高板日的自然身份。家数相同时比较题材成交额，不能用最高连板改写市场动向榜。

题材触发只决定梯队，不保证触发该题材的股票最终胜出；第二阶段仍需在已冻结的 `H` 层内重新选票。

### 3. 防守模型

节点股票已经属于收盘涨停池，因此真一字的唯一判定是同一价格口径下开盘价=最高价=最低价。T 字、高开秒封和开板回封均不算一字。

一个梯队形成防守模型的必要结构：

- 至少一只真一字锚；
- 同层至少一只自然票。公告一字可以只作量能，自然票负责候选资格。

防守模型不判断题材压制：一字锚与自然票可以是同一只股票，也不要求同题材。最高板日为公告 theme 的一字只能作量能锚，不能单独提供自然候选资格。

选择顺序：

1. 从最高自然层开始，按高度从高到低检查；
2. 选择首个含真一字锚与自然候选的梯队，不得越过有效三板直接落到二板；
3. 公告一字可以作量能锚，自然票负责候选资格。

### 4. 两种结构重叠时的模型名

若最高自然层同时满足进攻模型与防守模型，一律归为进攻模型。只有进攻模型不成立时，才从高到低检查防守模型。

### 5. 两者都不成立

进攻模型和防守模型均不成立时，只有存在自然二板候选才选择二板，模型记为“无”。如果二板最高板日 theme 全是公告，或市场没有二板，则本日不选层。

## 五、脚本与 AI 的边界

第一阶段脚本固定输出：

- 目标梯队；
- 模型字段：进攻模型／防守模型／无；
- 最高自然板；
- 开盘啦市场动向榜前二；
- 一字锚、公告量能和自然候选；
- `information_cutoff=T`。

第二阶段 AI 只能在脚本已选梯队内判断核心、补涨、风险和放弃，不得跨层推翻脚本。未来统计必须拆成“梯队命中率”和“梯队内选票命中率”。

## 六、第二阶段节点日竞价预期分

冻结梯队后，可在仍然只读取节点日 `T` 的前提下生成层内自然票次日竞价预期分 `E`：

```bash
python -m ultraboard.review.candidate_initial_score 2025-12-24
```

个股自身证据由五项等权组成：

1. 梯队模型与身位：20%；
2. 市场题材地位：20%，开盘啦市场动向榜名次占该项 80%，题材涨停家数占 20%；
3. 个股在评分题材内的身位与核心性：20%；
4. 首封主动性：20%，由绝对首封时刻和同题材自然队友相对次序组成；
5. 首封后传播：20%，统计此后才首次封板的同题材自然队友比例与数量。

日内主动性与传播合计 40%。公告票从自然队友时序中剔除，只单列量能。一字形态本身直接权重为 0：早封只能取得主动性证据，若没有市场题材地位、个股核心地位和此后传播，不能仅凭一字推导次日仍应一字。

节点日为自然票时，个股使用连续路径从二板起真实出现的各个 `theme` 分别形成完整论点；禁止拿题材 A 的市场排名、题材 B 的核心地位和题材 C 的传播拼成一个虚假高分。节点日最高板 theme 为公告时，该票不进入自然候选评分。

原始池只有首封时间，没有末封时间、开板次数和候选首封瞬间仍封住的队友数量。因此“前／同秒／后”只代表首次触板顺序，不代表当时封板状态，更不宣称候选因果带动了后续股票。

当前分值 `E` 表示节点日证据要求次日 09:25 给出多强的竞价，不是次日连板概率。次日实际竞价必须转换到同一刻度 `A`，超预期差为 `Δ=A-E`。后验结果只允许在显式校准入口中用于整体调权；禁止按单日结果改权重或写股票／日期特判。

同梯队 PK 的边界是第一阶段已经冻结的**全部自然票**，不要求题材相同，公告量能票不参与。先用个股自身证据分做两两强弱映射，再取对其余票的平均值作为预期 PK；分差 10 分约映射为 73／27，分差 20 分约为 88／12。多票梯队当前按“自身证据 90% + 预期 PK 10%”形成最终 `E`。如果梯队只有一只自然票，则 `pk_available=false`，不填中性 50 分，PK 实际权重归零，其余证据自动占满。

## 七、实际竞价与超预期差

显式后验入口：

```bash
python -m ultraboard.review.auction_score review 2025-12-22 --fetch-missing
python -m ultraboard.review.auction_score backtest \
  --labels .blind-test-quarantine/labels/stage1_locked.json \
  --fetch-missing
```

V2 把 T+1 集合竞价形成的开盘涨幅除以该股涨停幅度，再映射成自身开盘强度证据：平开为 50，涨停开为 100，跌停开为 0。多票梯队用同一映射比较全部自然候选，形成实际 PK，并按“开盘强度 90% + 实际 PK 10%”得到最终 `A`；同时单列 `PKΔ=实际PK-预期PK`，观察竞价时层内地位是否超预期。单票梯队仍由开盘强度占满。若多票梯队缺任一候选的 09:25 数据，则最终 `A` 与 `Δ` 明确缺失，不用降级公式制造不同刻度。历史库没有可靠的竞价成交额和 09:20～09:25 委托队列，因此竞价量、委托轨迹和全市场竞价一字结构均不补默认值，其中竞价一字因子按当前约定权重为 0。

超预期分组暂按 `Δ` 划分：

- `Δ≥15`：大幅超预期；
- `7≤Δ<15`：超预期；
- `-7<Δ<7`：符合预期；
- `-15<Δ≤-7`：不及预期；
- `Δ≤-15`：大幅不及预期。

收盘是否晋级独立放在 `after_close_outcome`，只用于后验校准，绝不参与 `E`、`A` 或 `Δ`。

## 八、回测边界

```bash
python -m ultraboard.review.ladder_selector backtest \
  --labels .blind-test-quarantine/labels/stage1_locked.json
```

这里统计的是与人工冻结标签的一致率，不是次日成功率。标签和算法输出必须分开保存；回测不允许让标签参与特征计算，也禁止为了单一日期写特判。

最终归纳：**进攻模型优先；没有进攻模型再检查防守模型；皆无且存在自然二板才落二板，否则不选。**
