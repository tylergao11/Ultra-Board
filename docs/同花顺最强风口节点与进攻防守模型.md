# 同花顺最强风口节点与进攻防守模型

## 一、当天身份

每只涨停股只使用当天同花顺“最强风口”的一个主分组。身份不沿途继承，也不回看后续日期。

- 同花顺已有明确分组时，保持该原始分组。
- 明确的公告类分组在节点计算中属于公告身份；名称仍保留同花顺原名，不强行改写。
- 只有“其他/其他概念/未分类”需要人工读取事件介绍并寻找真实封板驱动，最终不得保留兜底名。

## 二、如何人工审核真实驱动

“驱动原因”是当天资金为什么在这个时点把股票封上涨停，而不是公司能沾上的所有概念，也不是事件文字里最醒目的词。

逐股按以下顺序判断：

1. 看原图的完整事件介绍，不先做关键词匹配。
2. 看当天最强风口与同题材涨停群，判断它是否随板块联动。
3. 看封板时间和同板块先后关系：它是在题材爆发后跟随，还是独立事件率先封板。
4. 公司自身的拟收购、资产注入或并购预期、控制权变更、业绩预增等独立驱动，统一归“公告题材”。
5. 真正随行业、政策或概念群体上涨，归入当天对应自然题材。
6. 仍拿不准就保留待审问题，禁止脚本给建议或猜一个结果。

典型边界：年报预增若当天真实炒作的就是该公司预增，仍是公告驱动；芯片资产注入传闻、并购预期、控制权变更预期若构成该股独立封板原因，也属于公告题材。反之，事件介绍虽提到公告内容，但股票实际随一个强势自然板块联动，则按自然题材处理。

## 三、节点日

节点是最高有效自然梯队的集合事件：

1. 在交易日 `T-1` 收盘，取全市场二板及以上股票。
2. 按 `T-1` 当天同花顺主分组剔除公告身份。
3. 在剩余股票中确定最高板 `H` 及该层全部成员。
4. 到 `T`，只要 `H` 层仍有一只晋级 `H+1`，`T` 就不是节点日。
5. `H` 层全部断板时，`T` 才是节点日。

口语版：前一日最高板当天没有被同花顺归为公告身份，它所在最高层全部断板的交易日就是节点日。

## 四、进攻模型

节点日收盘冻结，只看节点日当天：

1. 剔除公告身份后，只在最高有效自然板判断。
2. 候选当天同花顺主分组必须位于“最强风口”前二。
   “其他概念”人工拆出的票只有并入海报已有明确大类时才继承该位次；新题材没有独立风口排名，不能借兜底容器排名过门槛。
3. 该分组当天必须另有更低板涨停支持，不能是孤立高标。
4. 一字或换手不是进攻模型的成立门槛。
5. 不读取候选沿途历史分组。

## 五、防守模型

1. 真一字是硬门槛，只认 `open == high == low` 的一字涨停。
2. 从最高有效自然层向下扫描，首个同时有真一字锚与自然候选的梯队形成防守模型。
3. 公告一字可以提供量能锚，但不能单独提供自然候选资格。
4. 同层换手支持有帮助，但不是硬门槛。

若节点日同时出现进攻与防守结构，主模型记“进攻模型”，防守结构记“次级防守模型”；无论防守结构与进攻层同层还是位于更低层，都必须显式保留其高度和成员。

## 六、输出术语

正式输出只使用：

- `进攻模型`
- `防守模型`
- `无模型`

梯队在 `T` 日收盘冻结；`T+1` 只用于同层 PK 与执行，不得倒灌改变节点日、选层或模型归属。
