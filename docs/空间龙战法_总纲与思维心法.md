# 《空间龙战法》总纲、铁律五步语序与核心思维心法

## 一、第一性原理

寻找**“全市场资金注意力绝对净空、头顶无更高一字封路、背后无同向人气老龙分流、出生时不沾老 5 板余孽、开板 5 分钟内资金秒抢回封”**的新周期空间龙第一接力点。

## 二、铁律五步观察语序（每天盘后/早盘固定动作）

### 第 1 步：先立“双轨高标背景池”（每天第一眼看谁在吸人气）

1. **A 轨 · 空间龙出生补涨禁区（严格卡 5b，含当日 5b 断板）**
   - **`4b` 一律不算**：只有首板出生日当天在途 `≥5b` 或当日 `≥5b` 断板的高标，才会把同方向首板打成补涨。
   - **热认知辐射半径**：只认高标真实发酵的主线及自身具备的同源热属性（例如高标同时具备同源 AI 硬件多分支则一并辐射，但绝不乱管冷门僵尸副标）、高标真实带起的核心主业共振分支、以及盘面批量发酵的字辈玄学（华字辈、羊/洋/阳/祥、东方）。
   - **地域严卡铁律（绝不硬凑）**：省份/地域属性**必须同时满足“有明确地域政策/事件消息 + 盘面同省批量涨停启动”**（如海峡两岸/福建）才算数；若无地域消息、无批量启动，即便客观同省甚至心里知道它在暗补，**也绝不把地域作为补涨或压制依据**。

2. **B 轨 · 当下人气工具人压场池（老高标反包二连+ / 超级加速高标 / 大趋势牛股）**
   - **精准触发线**：**老龙反包 1 连不管**；**反包 2 连及以上（或超级加速多板如 7天5板、8天5板、10天7板）立刻起效！**
   - 凡近期走出过强辨识度的高标/人气核心，只要在**候选票首开前最后一个一字日当天**仍在连板吸金，当天同方向所有一字连板（不论出生多干净、身位多高）全部降格为**工具人**直接废除。
   - **老龙断板压场即解**：压场老龙一旦断板放弃，同方向后续延续的一字先锋压场立刻解除。
   - **细分赛道绝不硬合**：AI 硬件等大类下不粗暴合并，只有精确命中同一细分热属性才压场。
   - **无同属性大趋势标杆**：确认场上没有同方向高位大趋势牛股吸走主资金才认先锋。

### 第 2 步：硬排除（七类一票否决）

1. **医药不做**：医药大桶一律直接跳过（注：**保健品归消费、不归医药**；以测量仪表等非医药主业跨界并购硬科技的标的除外）。
2. **带存续可转债的正股一律放弃**：凡正股当前存在存续交易可转债，无论盘面强弱一律跳过，避免游资借可转债 T+0 套利/打掩护分流正股承接（2026 年 1–11 月全部 39 笔成交已全量核验 100% 为纯正股、无存续转债）。
3. **百元高价股不玩**：股价在百元附近及以上的绝对高价股（如 `100` 元级）直接放弃（全口径 39 笔成交最高买入价仅 35.06 元，零误伤）。
4. **夕阳行业并购重组 / 无新产业资产注入的纯易主与划转不做（绝不对硬科技重组一刀切）**：
   - **直接排除**：“夕阳+夕阳”重组、无产业资产注入的纯壳实控人变更或股权协议转让/无偿划转（无估值锚重塑，熊市全军覆没）；
   - **保留穿透**：凡跨界切入**硬科技新赛道（芯片/光芯片/存储/磷化铟/锂电/算力等）的并购重组**，正常穿透至对应新赛道走五步流程——并购熊市期靠压制过滤与 **≤ 5 分钟硬买点** 自动做到几乎 0 亏损，并购强市期则能稳抓超级翻倍总龙。
5. **纯机构趋势加速连板不做**：大市值机构趋势票走出的 2 板/一字加速，不属于超短游资空间龙接力生态，直接跳过。
6. **畸形/透支形态或孤立空壳直弃**：
   - 超级多波透支（大四波、前期已走出大幅主升后的**超级大二波**及大二波反抽）；
   - 高频断板连拉的伪低位畸形图（如 5天4板/5天3板/6天4板伪装连板）；
   - 完全看不懂主炒逻辑且无任何板块梯队效应的孤立壳股。
7. **二次及以上一字首开直接放弃**：同一轮主升中途已换手首开过、后半段再度顶出一字的票一律不做。

### 第 4 步：更高身位一字压制（只认一字、含 20cm 同身位、非对称、熬死即解）

- 压制由低位唯一主炒向上查**更高身位严格一字**（及同身位 `20cm` 严格一字）的**真实热属性**（哪怕高一字自身出生有问题，只要还顶着一字就在吸同向资金）；
- 头顶为同向**换手**高标不构成静态压制（留给次日 09:25 竞价 PK 决胜）；
- 头顶压制一字次日断板，则压制立刻解除。

---

### 第 5 步：次日 09:25 竞价卡位 & 开板 ≤ 5 分钟硬买点（超时不要）

- **09:25 竞价卡位**：只与同身位及更高身位含候选唯一主炒的沪深主板对手比竞价（涨幅/同涨停开比初始封单），被卡即弃；
- **开板 ≤ 5 分钟硬买点**：
  - **非一字开盘**：须在 `≤ 09:35:00` 完成首次封板；
  - **一字开盘**：自首次开板起算，须在 **5 分钟交易时间内**（扣除 `11:30–13:00` 午休）完成首次回封；
  - 超过 5 分钟一律放弃（实盘复盘中绝大多数真龙都在 2 分半内极速触发，5 分钟线自动挡掉几乎所有假强与熊市重组雷）。
- **卖出规则**：买入次日起检查，首个收盘未涨停日按未复权尾盘收盘价卖出（不扣费用与滑点）。

## 三、为什么有些高标属性根本不在意？（有效属性三道筛）

机械扫概念表频频误杀的根源，是把几十个静态标签当成等权砖头；盘面实战只认**“此刻真能抢同一锅资金水的活属性”**，先砍三刀：

1. **第一刀：砍掉“已抛弃的旧壳主业”**
   - 当高标通过跨界并购或主线切换完成基因突变，市场资金只认它的新估值锚，原有传统旧壳业务彻底作废，绝不拿旧壳去压制别的独立主线。
2. **第二刀：砍掉“本轮 0 共振的冷门僵尸副标”**
   - 只要高标身上某个副属性在本轮上涨中既无消息催化、也无同向小弟跟随，它就不具备分流该板块资金的能力，绝不拿冷门副标去误杀真先锋。
3. **第三刀：砍掉“无消息、无批量启动的巧合同省标签”**
   - 大省上市企业众多，两只强势股碰巧同省绝不等于市场在炒地域；没有明确地域政策消息、也没有同省批量涨停启动，地域标签直接归零。

## 四、为什么绝不被开盘啦假标签欺骗？（穿透属性五面照妖镜）

1. **照妖镜 1 · 顶层霸主“有罪推定”向下反查（优先向高标靠拢）**
   - 永远先看当下谁在霸屏，再拿霸主属性往下反筛低位一字；**当低位一字同时挂着多个模糊标签时，优先向当下 5b+ 霸主主炒方向靠拢定性补涨**，绝不给跟风杂毛开绿灯：
     - 芯片/航天/算力主升霸屏 ➔ 标 `中报增长 / 一季报 / 物理AI / 光通信 / 智能电网` 的票，底稿只要带霸主核心属性（芯片、商业航天、算力），直接向高标靠拢判补涨/压制；
     - 机器人强势/一字压阵 ➔ 孤立冒出的 `消费电子 / 端侧AI / AI玩具 / 汽车零部件 / 商业航天` 第一眼默认怀疑为机器人混子从严核查；
     - AI 应用或字辈玄学霸屏 ➔ 披着 `黄金 / 农业 / 食品 / 服装` 外皮的票，一眼照穿其真实蹭靠对象。
2. **照妖镜 2 · 只信“集体梯队”，踢碎“孤立软件标签”**
   - 不在当日集体梯队里的孤立软件标签（例如单票突改标签、两天未进对应梯队、前一周炒 A 赛道突然硬标 B 赛道），一律先按假标签反查。
3. **照妖镜 3 · 牢记“历史股性记忆 & 核心主业”，剥光老油条马甲**
   - 近期刚走过主升辨识度的老龙、或长期主业清晰的老油条，换一层热点马甲贴脸时，直接按其市场公认的真实股性与主业还原。
4. **照妖镜 4 · 常态撕废壳，但绝不教条——以“批量板块效应”为准绳**
   - 孤立单票标 `业绩 / 中报增长 / ST摘帽 / 举牌` 一律撕掉（无逻辑无梯队的孤立壳股直接弃）；但当同一事件标签当天形成**集体批量涨停梯队**时，该事件本身就是资金共识堆出的独立主线，顺势认可、不死背教条。
5. **照妖镜 5 · 双栖票一锤定音法：看“谁家小弟给它推的一字”**
   - 当一只双栖票在两个方向上逻辑都讲得通时，不死抠年报字面，直接看 **2 板 / 推一字当天是哪边板块成批涨停助攻把它推成一字**，以此一锤定音。
