日期：2026-08-17
数据只读。本目录不修改 `ultraboard/` 交易逻辑。

## 1. 样本窗口（不补日）

## 3. 冻结定义

### 3.1 市场最高板 H(t)

`H(t) = max{ boards(s) | s ∈ 当日开盘啦涨停池 }`。
与文件顶层 `max_board` 应对齐；若不对齐以个股 max 为准并记入警告。

**最高板股票** L(t) = `{ s | boards(s) = H(t) }`。

### 3.2 断板（优先个股，不只看高度）

对交易日 t（存在 t-1）：

- **个股断板（操作定义，收盘可观测）** `leader_absent(t)`：
  L(t-1) 中每一个 code 都不在 t 的涨停池。
- **个股部分断板** `leader_any_absent(t)`：L(t-1) 至少一个不在 t 涨停池。
- **高度回落** `height_drop(t)`：`H(t) < H(t-1)`。
- **确认炸板** `leader_zha(t)`：缺席的昨日最高板出现在 t 的同花顺开板池且 `change_tag=LIMIT_FAILED`。
- **事后停牌续板** `leader_halt_expost`：缺席后，在后续窗口再次出现且 `boards >= 缺席前 boards`（允许中间停牌后续板）。**当日收盘不可知**，只用于诊断，不进交易规则。

高度回落 ≠ 个股断板。例：2026-08-03，`603221` 从 7/31 的 9 板消失，H 从 9 落到 6，但 8/06 以 10 板回归，属停牌续板而非断板。2026-08-07 `603221` 从 10 板消失且不在炸板池，属操作定义断板（弱杀/低开，未触及涨停）。

### 3.3 爆量

成交量股数不存在，只用 `amount` / `turnover_rate`。

对某最高板股票 s 在日 t，`boards>=2`：

- 回溯**外观相连的连板段**：从 t 往前找同一 code，若某日 `boards == 期望高度` 则纳入，期望高度减 1；若该日不在池中则跳过（允许停牌缺口）；若在池但高度不匹配则终止。
- 若存在至少 1 个前日：
  - `amt_ratio_prev = amount(t) / amount(prev)`
  - `amt_ratio_med = amount(t) / median(连板段前日 amount)`
- **爆量（冻结）**：`amt_ratio_prev >= 2.0`（只对连板段上一出现日）。
- `amt_ratio_med` 只作诊断列。全程中位数会被早期一字板的极小成交额拉低，不能当触发器。
- 无前日：爆量 = 未知，该日该股不进入「爆量条件」分子分母。
- 阈值 2.0 是事先约定，不是拟合结果。

市场日 `leader_baoliang(t)`：L(t) 中至少一只可判定且爆量。

### 3.4 连板接力候选（信号日 t，结果日 t+k）

信号在 t 收盘形成，观察 t+1 / t+2 / t+3。

候选 = t 日涨停池中同时满足：

1. `boards >= 2`
2. 名称不含 ST / 退
3. 不是当日已被排除的对象（规则另述）

**不是**「在 t+1 开盘去买 t+1 已经涨停的票」——那是未来函数。候选必须在 t 收盘已知。

分档（用于梯队）：

- `new_high`：`boards == H(t)`（当日新的最高板）
- `sub_high`：`boards == H(t)-1`（若 H(t)>=3）
- `mid_2_3`：`boards in {2,3}`
- `legacy_near`：相对昨日高度，`boards in {H(t-1)-1, H(t-1)-2}`（断板后高位残梯；高位整体塌方时经常为空）

同题材：候选 `theme` == 断掉的最高板 `theme`（主分类字符串相等）。多只最高板时，命中其中任一主题即可。宽松版（主题集合相交）只写入附表，不进主规则。

题材仍活 `theme_alive(t, theme)`：t 日涨停池中该 `theme` 的股票数 ≥ 2。
`theme_dead`：= 0。`theme_weak`：= 1。

### 3.5 结果（只声称数据能看见的）

对候选 s 在 t、前瞻日 u = next(t, k)：

| 结果 | 定义 | 可回测？ |
| --- | --- | --- |
| `zt_next` | s 出现在 u 的开盘啦涨停池 | 是 |
| `promote` | `zt_next` 且 `boards(u) == boards(t)+1` | 是 |
| `one_word_next` | `zt_next` 且同花顺 `one_price=true` 或 `board_type=一字板` | 是（不可成交） |
| `tradable_zt` | `zt_next` 且非 `one_word_next` | 是（仍不是成交保证） |
| `zha_next` | 不在涨停池，但在 u 开板池 `LIMIT_FAILED` | 部分（只有曾触板） |
| `absent_next` | 两池都不在 | 是（原因不明：弱杀/停牌/数据） |
| 打板买入收益 | 以涨停价成交再持有 | **不可回测** |
| 次日开盘买入、开收盘收益 | 需要全市场 OHLC/竞价 | **不可回测**：OHLC 只在涨停成功股上；竞价文件为空；开板池没有开盘价 |
| 断板股次日收益 | 需要断板股 OHLC | **不可回测**（开板池只有曾触板者的收盘涨幅，且无开盘价） |

主指标：`zt_next`、`promote`、`tradable_zt`。每个格子必须带 n。

**买入/卖出假设（本回测实际用的）**：不做价格成交。一条候选计一次试验：t 收盘选中，看 t+1 是否晋级/继续涨停。这是条件频率，不是资金曲线。

若要做价格路径回测，至少还缺：候选股在 t+1 的开盘价/竞价匹配量、以及断板股全日 OHLC。仓库里没有。

## 4. 规则候选（事先定死，不事后海选）

基线：

- **B0** 无条件：所有 `boards>=2` 的次日继续涨停（再按 2 / 3 / 4 / 5+ 分层）

对照用户假设：

- **R1** 最高板个股全断（`leader_absent`）后次日，接当日全部连板
- **R2** 最高板至少一只仍封（非 `leader_absent`）后次日，接当日全部连板
- **R3** `leader_absent` 后次日，接**同题材**连板
- **R4** `leader_absent` 后次日，接 **2–3 板**
- **R5** `leader_absent` 后次日，接当日新最高板（`boards==H(t)`）
- **R6** 最高板爆量且仍封（`leader_baoliang` 且非 `leader_absent`）后次日，接同题材连板
- **R7** 高度创新高日（`H(t) > max(H[t-20:t-1])`，不足 20 日则用已有日）次日只接 2–3 板
- **R8** 高度创新高日次日不接（该日候选 n 记为 0，只作对照）
- **R9a/b/c** `leader_absent` 后 lag1 / lag2 / lag3：候选取断板日后第 k 日仍在池的连板，结果看再下一日

不做参数搜索。爆量阈值、20 日新高窗口都是事先写死。

## 5. 验证

- **时间对半**：有次日的信号日按时间切成前半 / 后半，规则必须在**两半都**满足才算存活：
  - 该半 `n >= 30`
  - `tradable_zt` 率 ≥ 同半 B0 基线（按候选计）
- **Walk-forward**：信号日滚动，训练 40 日、测试 20 日、步长 20。训练段只用于看样本内是否好看，**不调参**。存活还要求多数 `n>=15` 的测试折 `tradable_zt` ≥ 该折 B0。
- `n < 15`：不声称。`15 <= n < 30`：弱。
- 只在样本内赢、对半或样本外翻车 → 拒绝该规则。
- 可以没有「最佳切入点」。没有规则跨半存活，结论就是没有。
- **高度匹配**：若规则选出的票平均比 B0 更高，会虚高。对每条候选用「同样 boards 的无条件可买续板率」做期望，残差 = 实际 − 期望。宣布切入点还要求两半残差 ≥ 0。这是稳健性门，不产生新规则。
