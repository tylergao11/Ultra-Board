## 方法（系统性，不是手感）

只用 t 日可知字段。次日字段只作成败，不作条件。未改 `run.py` / `ultraboard/`。

**单因子（已有列 + 同日拼接）**
- 高度：boards 2/3/4/≥4/≥5/≥6，height_bucket
- H 相对：href=0/1/2/≤1/≤2（新高/次高/H-2）
- 题材：日级 `theme_alive`/`theme_dead`（断板题材，原表）；`theme_alive_own`（该股题材当日全涨停池≥2 只，同日重算）
- 断板：`leader_absent` / `height_drop` / lag0–3（距最近一次龙头缺席的交易日数，0=断板当天）
- 爆量：龙头当日/前日、同题材龙头、自身相对前日连板成交额≥2
- 一字 vs 换手：`one_price_today`、`open_count`（0 / ≥1 / ≥2）、当日成交额/换手分位
- 反包：`is_fanbao`（开盘啦同日）
- 市场：H 桶、涨停家数、龙头只数

`open_count` / `is_fanbao` / 成交额 / 换手从同日 `data/kaipanla/raw/*/zt_pool.json` + `data/ths/limit_pool` 拼接，不写回核心逻辑。

**2 因子**：20 个核心布尔的正反配对网格。

**3 因子**：预动机组合（梯队 / 接力 / 题材 / 断板 / 爆量 / 一字 vs 换手）+ 9 核布尔正反三重。

评估组合去重后 **1548** 个 × 3 定义。另做连续阈值扫描（boards/H/href/lag/theme_n/open_count/amount/turnover/分位/n_zt）和题材名切片（只作垃圾检查）。

覆盖核对：fanbao=112，opened=1525，unopened=1211，theme_alive_own=2281，own_baoliang=359，lag0=1098，lag1=742。

## 泄漏 / 垃圾 90% 检查

| 风险 | 结果 |
| --- | --- |
| 一字今日 → 一字明日 | **主假阳性源**。`one_price_today` zt_next 69.3% / tradable 31.5%。`one_price & boards≥6`：81% vs **21%**。低量/低换手只是一字的代理（amount≤5e7 一字：zt 86.8% / tradable 21.7%） |
| 小 n | n=17 的 88.2% 后半只有 2 条；n=31 的 48.4% tradable 前半 n=11 |
| 高度混杂 | 已在 notes 写 height mix。高 zt_next 切片高度偏 5+ 一字 |
| 次日字段入选 | 未使用 zt_next / one_word_next / boards_next / zha_next 做筛选 |
| 题材名 1–2 只 | 未把单题材当因子家族。最高题材切片：食品饮料 tradable **52.8% n=36**、煤炭 48.1% n=27，仍远低于 90%，且不可外推 |
| 停牌续板 | 候选只来自当日涨停池，没有用「后来复牌再上」回填选股 |
| 反包 | n=112，zt_next 25.0%，tradable 22.3%，低于基线 |
| 连续阈值 | 无任何单阈值在 tradable 上超过 ~32.5%（boards≥3）。zt_next 上能到 75%+ 的阈值全是低额/低换手（一字代理），最高 77.4% n=274，不是 90% |
